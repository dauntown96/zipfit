# 📚 꼭집 주거 사전 — 재계산 SQL

Notion 「📚 꼭집 주거 사전」 DB의 각 행이 가리키는 **재계산 SQL의 정본**이다. Notion 「재계산 SQL」 칸에는 이 폴더의 파일 경로만 적는다.

- **왜 파일인가**: Notion text 칸이 마크다운을 해석해 SQL을 소리 없이 바꿨다(`\s` → `s` · 짝 `*` → 기울임 · `[^.]` 삭제 — 2026-10-13 사전 시드 회차). 파일은 바뀌지 않는다.
- **읽기만 한다**: 모든 파일은 `select` 한 문장이다(쓰기 0). 관리 API(`POST /v1/projects/<ref>/database/query`)에 파일 내용을 그대로 실어 실행한다. 머리 주석(`--`)도 함께 보내도 된다.
- **범위**: 공고일이 2026년인 공고만 센다(`a.yr = 2026` · 유효 연도가 바뀌면 이 값을 바꾼 새 판을 만든다). 유형은 `housing_type_map`의 표준값(`std_type`)으로 접는다.
- **머리 주석**: 사전 항목 이름 · 확인일 · 실행 시간 · 그때 결과(JSON). 결과는 기록일 뿐 정본이 아니다 — 지금 값은 다시 돌려서 본다.
- **정규식 근사**: 대부분의 행은 정책 행(`announcement_policies`) 문장에 낱말 꼴이 있는지를 센다. 근사 여부와 한계는 Notion 행의 「내부 메모」에 적는다.
- **시간**: 관리 API 응답은 약 30초에 끊길 수 있다. 지금 가장 긴 파일은 `conversion-rate-lh.sql`(약 17초)이다.

파일을 고치면 Notion 행의 「현재 판」·「근거 공고 수」·「마지막 확인」도 같은 회차에 다시 적는다.
