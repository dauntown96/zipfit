# Notion 블록 옮기기 — `scripts/notion-move.py`

2026-11-23 · 우편함 「조사·정리 — Notion 기록처 정리 2회차」. 1회차(⑩ 나누기 · ⑧ 9월 판례 · L2-L 월별)에 쓴 임시 스크립트를 저장소로 옮긴 것이다. 큰 Notion 페이지의 절을 **글자 그대로** 다른 페이지로 옮길 때 쓴다(Notion MCP에는 블록 옮기기 도구가 없다).

## 무엇을 하나

1. **받기** — 원본 페이지의 블록 트리를 공개 API로 받아 상태 파일에 시작 덤프로 남긴다.
2. **붙이기** — 새 페이지(또는 있는 페이지의 어느 블록 뒤)에 블록 JSON을 그대로 붙인다.
3. **대조** — 새 자리를 다시 받아 블록마다 (깊이 · 종류 · 글자 · 서식 조각)를 원본과 맞댄다. 인접한 같은 서식 조각은 합쳐서 본다.
4. **삭제** — 전부 같을 때만 원본 블록을 지운다. 그 뒤 (있으면) 옮긴 자리 한 줄과 색인 줄 링크 바꾸기.

대조가 어긋나면 새로 붙인 것을 지우고 원본을 그대로 둔 채 멈춘다(종료 코드 2 · 상태 파일은 `.mismatch`로 바뀐다).

## 준비

- 환경 변수 `NOTION_TOKEN`(내부 통합 토큰). 값은 찍지 않는다. 통합이 연결된 페이지만 읽고 쓴다(우편함은 연결 밖 — 읽기 404).
- 🔴 Notion 쓰기는 루틴 대기열이 0일 때만(우편함 규칙).
- 🔴 옮기기 전 원본 페이지 복제본을 L3에 하나 둔다(MCP `duplicate-page` → `move-pages`).

## 명령

```bash
python3 scripts/notion-move.py tree <페이지> -o 덤프.json
```

```bash
python3 scripts/notion-move.py sections <페이지> -o 절.json
```

```bash
python3 scripts/notion-move.py oversize <페이지>
```

```bash
python3 scripts/notion-move.py move 계획.json --dry-run
```

```bash
python3 scripts/notion-move.py move 계획.json
```

- `tree` — 블록 수 · 글자(블록 `plain_text` 합).
- `sections` — `#`·`##` 머리마다 절(머리 ~ 다음 `#`·`##` 앞 · 하위 페이지에서 끊음)의 블록 id · 글자. 계획을 짤 때 쓴다.
- `oversize` — 서식 조각이 100개를 넘는 블록(아래 「자리표시」).
- `move --dry-run` — 쓰지 않고 윗단·블록·글자·덩어리 수 · 자리표시가 될 블록만 찍는다.

## 계획 파일

```json
{
  "src": "<원본 페이지 id>",
  "blocks": ["<옮길 윗단 블록 id>", "…"],
  "dest": {"new": {"parent": "<새 페이지의 부모 id>", "title": "📦 ⑧ 2026-10 판례"}},
  "head": [],
  "marker": "→ 2026-10 판례 {n}절은 {dest} 로 옮김",
  "relink": [["<색인 줄 블록 id>", "<옮길 머리 블록 id>"]]
}
```

- `blocks` — 원본의 윗단 블록 id(원본 순서대로). 떨어진 덩어리 여럿이어도 된다.
- `dest` — `{"new": …}`(새 페이지) 또는 `{"page": "<id>", "after": "<그 페이지의 블록 id>"}`(있는 페이지의 그 블록 뒤 — 없으면 끝).
- `head` — 새 자리 맨 앞에 먼저 붙일 블록(읽은 꼴 그대로 · 머리말 등). 대조에는 안 들어간다.
- `marker` — 원본의 덩어리마다 그 앞 블록 뒤에 넣는 한 줄. `{n}` = 그 덩어리의 `#`·`##` 머리 수 · `{dest}` = 새 자리 멘션. 덩어리가 원본 맨 앞이면 멈춘다.
- `relink` — 색인 줄 글자는 그대로 두고 링크만 새 자리의 그 머리(`…#<블록 id>`)로 바꾼다.

## 끊겨도 이어 하기

상태 파일 `<계획>.state.json`에 시작 덤프 · 새 자리 · 새 블록 id · 대조 결과 · 지운 블록 · 옮김 줄 · 바꾼 링크를 적는다. 같은 명령을 다시 부르면 남은 단계부터 한다. 원본 블록이 시작 덤프 뒤에 고쳐졌으면(`last_edited_time`이 다르면) 멈춘다 — 상태 파일을 지우고 처음부터.

🔴 백그라운드로 돌릴 때는 시간 한도를 넉넉히 건다(1회차에 10분 한도로 지우기 도중 끊겼다 — 지금은 상태 파일로 잇는다).

## 자리표시 — 서식 조각 100 넘는 블록

공개 API는 한 블록의 서식 조각(`rich_text`)을 100개까지만 만든다(Notion 화면은 더 만든다). 그런 블록은 글자 「ZZPH-<원본 블록 id>」로 만들고, 그 목록을 찍은 뒤 종료 코드 3으로 멈춘다.

1. 원본 페이지를 Notion MCP `fetch`로 받아 그 블록의 마크다운 줄을 찾는다(파일로 떨어지면 `jq`·python으로).
2. 새 자리에서 MCP `update-page` `update_content`로 「ZZPH-<id>」 → 그 마크다운(줄머리 `- ` 빼고).
3. 같은 `move` 명령을 다시 부른다 — 대조부터 잇는다.

🔴 마크다운을 손으로 옮겨 적으면 글자가 틀린다(1회차에 두 번 — 대조가 잡았다). 어긋나면 그 덩어리를 원본에서 다시.
